## About This Portfolio

This is my **next-generation personal portfolio** — built from the ground up with cutting-edge web technologies in 2025.

A perfect blend of sleek design, smooth animations, and interactive 3D elements powered by Three.js and React Three Fiber.

### Highlights
- Interactive 3D Hero with a customizable desktop model (mouse-reactive)
- 3D Skills section with animated geometric shapes
- Smooth project & testimonial animations using Framer Motion
- Contact form featuring a rotating 3D Earth (real email sending via EmailJS)
- Dynamic starfield background generated with Three.js
- Fully responsive across all devices
